Validation : comparer les modèles et régler les hyperparamètres.

Test : note finale, utilisé une seule fois.

stratify=y garde les proportions de classes dans chaque ensemble. Avec la validation croisée, le bloc Validation est remplacé par les folds.
from sklearn.model_selection import train_test_split

# 1) on met 20 % de côté pour le test final
X_tmp, X_test, y_tmp, y_test = train_test_split(
    X, y, test_size=0.20, stratify=y, random_state=42)

# 2) on coupe le reste en Train / Validation
X_train, X_val, y_train, y_val = train_test_split(
    X_tmp, y_tmp, test_size=0.20, stratify=y_tmp,
    random_state=42)

3. Cinq modèles, un même protocole

Même split, même pipeline de prétraitement, mêmes métriques : seule la dernière étape change.

Entraîner sans data leakage

from imblearn.pipeline import Pipeline
from imblearn.over_sampling import SMOTE

pre = ColumnTransformer([
 ("num", Pipeline([("imp", SimpleImputer(strategy="median")),
                   ("sc", StandardScaler())]), num_cols),
 ("cat", Pipeline([("imp", SimpleImputer(strategy="most_frequent")),
                   ("oh", OneHotEncoder(handle_unknown="ignore"))]),
  cat_cols)])

models = {"LogReg": LogisticRegression(max_iter=1000),
          "Tree": DecisionTreeClassifier(max_depth=5),
          "RF": RandomForestClassifier(n_estimators=300),
          "KNN": KNeighborsClassifier(),
          "SVM": SVC(probability=True)}

for name, clf in models.items():
    pipe = Pipeline([("pre", pre), ("smote", SMOTE(random_state=42)),
                     ("clf", clf)])
    pipe.fit(X_train, y_train)
    pred = pipe.predict(X_val)
    print(name, f1_score(y_val, pred, average="macro"))
Tout est dans le pipeline

Imputation, standardisation et encodage sont appris sur le train seulement, puis appliqués tels quels à la validation et au test.


SMOTE uniquement sur le train

Avec le Pipeline d’imblearn, le sur-échantillonnage ne s’exécute qu’au fit, jamais sur la validation ni le test.

4. Mesurer la qualité

Accuracy

Bonnes prédictions / total. Trompeuse si les classes sont déséquilibrées.

Precision

TP / (TP + FP). Quand je prédis cette classe, ai-je raison ?

Recall

TP / (TP + FN). Combien de vrais cas ai-je retrouvés ?

F1-score

Moyenne harmonique de precision et recall.


average="macro" traite les classes à égalité, "weighted" pondère par leur effectif. Pour des classes déséquilibrées, regardez le macro-F1.

Cliquez une classe. Lignes = réel, colonnes = prédit.

5. Validation croisée et réglage

cv = StratifiedKFold(n_splits=5, shuffle=True,
                     random_state=42)

scores = cross_val_score(pipe, X_train, y_train,
                         cv=cv, scoring="f1_macro")
print(scores.mean(), scores.std())

grid = GridSearchCV(
    pipe,
    {"clf__n_estimators": [200, 400],
     "clf__max_depth": [None, 10, 20]},
    cv=cv, scoring="f1_macro", n_jobs=-1)
grid.fit(X_train, y_train)
print(grid.best_params_, grid.best_score_)

# test final : une seule fois
best = grid.best_estimator_
best.score(X_test, y_test)

6. Sauvegarder et recharger

Joblib

Recommandé par scikit-learn : efficace pour les gros tableaux NumPy (forêts, KNN).


import joblib
joblib.dump(best, "pipeline.joblib")
pipe = joblib.load("pipeline.joblib")
pipe.predict(new_df)

Pickle

Module standard de Python, fonctionne pour tout objet.


import pickle
with open("pipeline.pkl", "wb") as f:
    pickle.dump(best, f)
with open("pipeline.pkl", "rb") as f:
    pipe = pickle.load(f)
Sauvegardez le pipeline complet, pas seulement le modèle : l’app Streamlit pourra prédire sur des données brutes.
Ne chargez jamais un fichier inconnu : pickle peut exécuter du code.
Gardez les mêmes versions de scikit-learn et Python au chargement.

7. Lire la matrice de confusion

y_pred = best.predict(X_test)

ConfusionMatrixDisplay.from_predictions(
    y_test, y_pred, normalize="true", cmap="Blues")

print(classification_report(y_test, y_pred))

Diagonale : prédictions justes. Hors diagonale : erreurs, ici Modéré prédit Élevé (9 cas) et Élevé prédit Modéré (6 cas).

Erreur la plus grave : un risque élevé prédit faible. Surveillez le recall de la classe « Élevé ».
